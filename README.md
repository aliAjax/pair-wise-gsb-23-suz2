# hxwl-09 半导体洁净室巡检

洁净等级阈值、粒子计数与异常处理看板 —— 可落盘的复核闭环。

## 技术栈

React + Vite + TypeScript + CSS（无新增依赖）

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5109

## 复核闭环规则

- 巡检记录包含：房间、洁净等级（ISO 5–8）、粒子计数（≥0.5µm，个/m³）、压差（Pa）、设备状态、处理备注
- **进入异常待复核**：粒子计数超过所选 ISO 等级上限（ISO 14644-1），或压差为负
- **关闭条件**：已保存的最新读数中，处理备注已补全 且 设备状态为停机或检修；不满足则拒绝并写入冲突列表
- **冻结与补录**：关闭后原读数冻结；再次录入视为补录，必须填写原因，生成新版本并保留全部旧值
- **草稿隔离**：未保存草稿按房间各自存放，切换房间不串台
- **落盘一致**：记录、复核状态、版本链、冲突与草稿均持久化到 localStorage（键 `hxwl09.cleanroom.audit`）；刷新时重算校验，发现版本链断裂、非法关闭、状态不一致即修复并生成冲突条目（房间、读数项、原值、新值、触发规则）

## 目录结构

```
src/
  domain/            # 领域层：数据与规则，不依赖界面
    types.ts         #   记录、版本链、关闭点、冲突、草稿等模型
    iso.ts           #   ISO 14644-1 ≥0.5µm 粒子浓度上限表
    rules.ts         #   异常判定、关闭条件、冻结补录、状态推导（纯函数）
    store.ts         #   localStorage 落盘 + 加载时完整性校验与修复
    seed.ts          #   演示种子数据（覆盖正常/待复核/已关闭/补录）
    time.ts          #   时间戳工具
  state/
    useInspectionStore.ts  # 状态层：按房间隔离的草稿与全部动作
  components/        # 界面层
    RoomList.tsx     #   房间列表（状态徽章 + 草稿标记）
    RecordDetail.tsx #   读数表单、关闭条件清单、实时规则预判
    VersionChain.tsx #   版本链（旧值冻结保留、关闭点标记）
    ConflictPanel.tsx#   冲突列表（房间/读数项/原值/新值/触发规则）
    MetricCards.tsx / StatusBadge.tsx
  App.tsx            # 组装
```
